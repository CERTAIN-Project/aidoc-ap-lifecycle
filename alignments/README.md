# Alignment proposals

`proposed.ttl` holds SKOS mappings (skos:exactMatch, closeMatch, broadMatch, narrowMatch, relatedMatch) from module terms to terms of the AIDOC-AP core and of the vocabularies vendored with it, one mapping per line with its rationale as a comment. `proposed-reified.ttl` holds the same mappings as `align:Mapping` records, the format of the core alignments (docs/resources/*-alignments.ttl in the core repository), generated by `make alignments`.

These are proposals. The core alignments were curated by three domain experts (2-of-3 majority vote, joint adjudication of splits). The module mappings go through the same curation before they are published; the curation adds `align:curationOutcome` to each record.

## Checks

`make alignments` fails if a subject is not a module term, if a target is declared neither in the core nor in the vendored vocabularies, if a relation is not a SKOS mapping property, or if a mapping has no rationale.

Mappings whose subject is a core term (for example core stage classes to the ISO/IEC 22989 stages of DPV-AI) belong to the core alignment process, not to this folder.
