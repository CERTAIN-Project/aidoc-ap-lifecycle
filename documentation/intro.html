Introduction back to ToC

The AIDOC-AP Lifecycle Extension adds to the AIDOC-AP core what is needed to follow an AI system through its lifecycle: which activity produced, packaged, tested, deployed, monitored or retired which model, and with which settings, formats, results and reasons. The core describes the technical documentation required by Annex IV of the EU AI Act and already has an activity class for each lifecycle stage. The extension connects these activities to the artefacts they use and produce, and gives each stage the descriptive properties that the CERTAIN Semantic MLOps Engine records. It imports the core without changing any of its definitions, and it reuses PROV-O, ML Schema, DQV and DPV wherever a term exists.
